# Локальная речь: Qwen3-ASR 0.6B

Приложение использует `sherpa_onnx` и INT8-версию Qwen3-ASR 0.6B. Распознавание выполняется на устройстве, аудио не отправляется в интернет.

Модель: https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-qwen3-asr-0.6B-int8-2026-03-25.tar.bz2

В каталоге приложения `ApplicationSupport/models/qwen3_asr` должны находиться:

- `conv_frontend.onnx`
- `encoder.int8.onnx`
- `decoder.int8.onnx`
- `tokens.txt`
- каталог `tokenizer/`

Для демонстрационной веб-сборки большие веса намеренно не включаются. Она показывает полный сценарий заполнения на тестовой расшифровке. В Android/iOS-сборке `Qwen3LocalAsrEngine` автоматически включает настоящее локальное распознавание, когда файлы модели установлены.

Перед production-сборкой модель следует либо включить в защищённый пакет установки, либо один раз загрузить из российского хранилища с проверкой SHA-256. Сама запись после установки сети не требует.
