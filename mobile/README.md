# РЕЙС Mobile

Flutter-прототип мобильного рабочего места экспедитора.

## Что работает

- голосовая заметка или свободный текст превращаются в структурированный черновик рейса;
- ручной ввод остаётся полноценной альтернативой;
- маршрут, дата, груз, вес, кузов, клиент и две ставки проверяются перед сохранением;
- маржа рассчитывается сразу;
- клиентов и перевозчиков можно добавлять, редактировать и удалять;
- показаны активные рейсы, календарь погрузок/выгрузок, исключения, документы, оплаты и водительские ссылки;
- черновик сохраняется локально;
- поручение экспедитору, экспедиторская и складская расписки привязаны к приказу ФНС № ЕД-1-26/277@;
- отдельные PDF-шаблоны, XML-предпросмотр и сценарий мобильной УКЭП/МЧД → оператор ИС ЭПД;
- интерфейс проверяется на 360×640, 390×844 и 430×932.

## Локальная речь

Нативные сборки подготовлены для Qwen3-ASR 0.6B INT8 через `sherpa_onnx`. Аудио обрабатывается на устройстве. Веса модели не лежат в Git — см. [MODEL_SETUP.md](MODEL_SETUP.md).

Если модель не установлена, Android-распознавание работает непрерывной сессией: пауза завершает только внутренний сегмент, приложение автоматически запускает следующий и склеивает текст без повторов. Заполнение полей проверяется более чем на 180 вариантах разговорных заявок.
