# ТрансКонтур — TMS Lite MVP

Локальный MVP диспетчерской для небольшого автоперевозчика. Он закрывает один основной сценарий: принять заявку, назначить экипаж, провести рейс по статусам, собрать документы и увидеть маржу.

## Что работает

- создание и поиск рейсов;
- фильтрация по статусам и карточка рейса;
- назначение водителя и автомобиля при создании;
- ручное движение по статусам с историей изменений;
- контроль заявки, транспортной накладной и закрывающих документов;
- плановые и фактические затраты, маржа и рентабельность;
- справочники водителей и автомобилей;
- демонстрационная клиентская страница статуса;
- экспорт JSON, импорт резервной копии и CSV для Excel;
- сохранение данных в `localStorage` и установка как PWA.

## Чего намеренно нет в локальном MVP

Нет серверной базы, авторизации, фонового GPS, реальной отправки уведомлений, 1С и обмена с оператором ИС ЭПД. Эти части стоит добавлять после 2 платных пилотов и выбора конкретного оператора ЭПД. Для пилотной версии данные следует перенести в PostgreSQL, добавить роли, журнал действий, резервное копирование и защищённые клиентские ссылки.
